# Hospital AI Copilot

## Overview
Hospital AI Copilot is an AI-powered clinical assistant designed to analyze patient history and provide relevant medical insights using Retrieval-Augmented Generation (RAG). The system retrieves similar medical cases and generates structured outputs to support clinical decision-making.

## Key Features
- Retrieval of similar patient cases using embeddings  
- Context-aware responses using RAG architecture  
- Structured clinical insights generation  
- Improved decision support for medical analysis  

## Tech Stack
- Python  
- Large Language Models (LLMs)  
- Retrieval-Augmented Generation (RAG)  
- Embeddings  

## How It Works
1. Patient history is provided as input  
2. Relevant medical data is retrieved using embeddings  
3. Retrieved context is passed to an LLM  
4. The system generates structured clinical insights  

## Results
The system enhances decision-making by providing contextually relevant and structured medical insights based on patient data.

## How to Run

- Run all cells step-by-step  
- Provide sample patient data as input
